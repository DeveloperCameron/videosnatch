⚙ Setup Required

VideoSnatch uses yt-dlp under the hood. Install it first:

macOS: brew install yt-dlp

Windows: winget install yt-dlp or download from GitHub releases

Linux / pip: pip install yt-dlp

You'll also need ffmpeg for merging audio+video: brew install ffmpeg / winget install ffmpeg
